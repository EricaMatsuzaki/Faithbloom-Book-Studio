# FaithBloom Agent Skills

Esta pasta documenta a camada formal de competências introduzida no Refinamento 21.
Os agentes não recebem o rótulo de “especialista” apenas por nome: cada papel possui
missão, skills obrigatórias, critérios de qualidade, limites, evidências necessárias
e handoffs esperados em `agent_skills.py`.

O sistema **não promete best-seller**. O Bestseller Readiness avalia fatores
controláveis e distingue inferência de IA de evidência observada de mercado.
